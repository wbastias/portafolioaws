APLICATIVO WEB SERCOM BODEGA

Aplicativo web de gestión de inventario de bodega desarrollado con Django (Python), Docker y SQL Server. APLICATIVO YOUSCAN

Plataforma de analítica de redes sociales orientada a marketing digital, que automatiza la ingesta, transformación y explotación de datos provenientes de YouScan.
